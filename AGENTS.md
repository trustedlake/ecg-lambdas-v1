# ecg-lambdas-v1: where the ECG algorithm lives

**This repo is the single source of the extraction algorithm.** Evaluation (`trustedlake/ecg-analyser`) and the production `ecg-reading` image run the same files. History = git branches, commits and tags, never copies or `v1/v2` folders.

| Edit here | Path |
| --- | --- |
| Extractors, layout, grid, calibration | `lambdas/real_reading/algorithm/{ecg,research_methods,review,configs}/` |
| Selector scoring code (model is NOT in git) | `lambdas/real_reading/algorithm/selector/{score,features,data}.py` |
| Which methods run in production | `algorithm/research_methods/registry.py` (six methods) |
| Research-only methods (evaluation) | `algorithm/research_methods/research_registry.py`, `submitted_adapter.py` |
| Lambda handler / contract | `lambdas/real_reading/src/lambda_v1.py`, `lambdas/ecg_contract/` |

| Do NOT edit | Why |
| --- | --- |
| `research_methods/frozen_peaks34/` | Historical Peaks34 control; `manifest.json` hashes are tested. |
| `research_methods/peaks34_reference.py` | Pinned by hash in `tests/test_algorithm_source.py`. New behaviour = new method. |
| `lambdas/real_reading/build/` | Generated by `assemble.sh`. |
| `selector/model_selector.pkl` (approved `cb0f395367ec`) | Never retrain/overwrite; `model.sha256` is checked in CI. |

## Test
```
python -m pytest lambdas/real_reading/tests -q
python -m unittest discover -s lambdas/tests
```
`tests/test_algorithm_source.py` fails on: edited Peaks34, changed production registry, imports outside `algorithm/`, a second copy of the algorithm.

## Package and publish
- `bash lambdas/real_reading/assemble.sh` (needs `models/model_selector.pkl`) copies `algorithm/` into `build/app`, fails if its digest differs, and writes `ALGORITHM_SOURCE.json` (digest + commit) into the image.
- `source_info.identity()` gives the same digest in evaluation; store it with every result.
- A push to `main` of `trustedlake/ecg-lambdas-v1` deploys to production (CodePipeline `ecg-lambdas`). Branches and PRs do not. Never push to `main` directly; open a PR.

Evaluation tooling and the research log are in `trustedlake/ecg-analyser` (`AGENTS.md` there).
